# 🧪 Chemistry Lab Management System

## 📘 Project Overview
This is a **Chemistry Lab Management System** developed in **Python** with database connectivity.
It helps manage chemicals, equipment, user accounts, and billing records efficiently.

The project was originally created for my **12th-grade Computer Science project** and has been improved during my **B.Tech CSE (AIML)** journey at **SVVV University**.

---

## ⚙️ Technologies Used
- 🐍 **Python 3**
- 🗃️ **MySQL / SQLite (auto-detection)**
- 📱 Tested on **Pydroid 3 (Android)** and **Windows**

## 💻 Features
- 🧍 User Registration & Login System
- ⚗️ Manage Chemical Inventory
- 🧰 Manage Equipment Records
- 🧾 Claim & Billing Management
- 🗄️ Dual Database Mode:  
  - **MySQL** on Windows  
  - **SQLite** automatically on Pydroid (Android)
- 🎨 Clean banner and menu interface

---

## 🚀 How to Run the Project

### 🧠 Step 1: Install Required Libraries
In terminal or Pydroid pip console:
pip install mysql-connector-python tabulate


### 🧠 Step 2: Run the Main File
python Main.py


✅ The database will be created automatically if it doesn’t exist.  
You’ll see the project banner and main menu.
